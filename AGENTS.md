# ThatAdGame

## Purpose and architecture
Browser crowd shooter with 50 worlds and three stages per world. Plain JavaScript ES modules and vendored Three.js, with no build step or backend.
- `index.html`: UI, styles and import map.
- `src/title-scene.js`, `src/title-screen.css`: animated title screen, isolated camp diorama and audio/menu-motion settings. Uses the existing renderer and sculpted troop, weapon, vehicle and scenery assets.
- `src/main.js`: rendering, simulation, input, saved progress and debug hooks.
- `src/levels.js`, `src/levels2.js`, `src/campaign.js`: stage definitions, equipment routes, pacing and announced flanks. `src/levels3.js` holds worlds 21 to 50, their themes, bosses and per-stage target HP table; `campaign.js` resolves their `hpF`/`needF` fractions against each stage target in `prepareLate`.
- `src/props-late.js`: procedural models for the late mechanics (bumper, hypno gate, rails and cart, harvest bank, egg, fusion core and beam).
- `src/biomes-21.js`, `src/biomes-36.js`, `src/biomes-late.js`, `src/decor-21.js`, `src/decor-36.js`, `src/decor-late.js`, `src/scenery-21.js`, `src/scenery-36.js`: palettes, fort families, flank kinds, map art and scenery for worlds 21 to 50.
- `src/arsenal.js`: thirteen troop ranks, ten weapons, eight vehicle forms, the two form abilities, three aircraft grades and swept circle collision.
- `src/troop-forms.js`: sculpted allied rank forms, the enemy raider and enemy gear overlays. `src/weapon-assets.js`: the ten sculpted troop weapons.
- `src/unit-assets.js`: troop geometry builder, ghost overlay and stride shaders. `src/vehicle-assets.js`: lofted vehicle hulls, the starting carriage, the lathe barrel and the charge-orb socket. `src/air-assets.js`: lofted aircraft with airfoil wings, canopies and lathe nacelles.
- `src/asset-kit.js`, `src/boss-shapes.js`: batched surfaces, continuous anatomical lofts, swept forms, domed armor and folded cloth.
- `src/boss-sculpted-core.js`, `src/boss-sculpted-late.js`, `src/boss-sculpted-royal.js`, `src/boss-sculpted-carnival.js`, `src/boss-sculpted-wild.js`: the full sculpted boss roster (32 types, including jack, flipper, ringmaster, mesmer, locomotive, scarecrow, panda, shogun, trex, roc, clockwork and overlord). `src/bosses.js` adapts the late builders.
- `src/fort-assets.js`: sculpted biome forts (curved curtain wall, pillowed stone courses, arched gatehouse, one tower design per family). `src/battlefield-assets.js` re-exports it and builds the lathe-and-loft turret, vaulted igloo and ribbed dome bunkers, jersey-barrier divider, toothed hydraulic crusher and fluted falling pillar.
- `src/scenery-assets.js`: sculpted roadside props (saguaros, rock clusters, pines, palms, coral, lollipops, columns, gears, crates, mountains, crystals and more) used by `models.buildWorld` and `src/worlds.js`.
- `src/map.js`, `src/map.css`: biome island map and progressive unlocks.
- `src/records.js`: personal bests and medals per world under `swarm-records` (pure `recordRun`, `medalsOf`, `clock`). Stars stay in `swarm-progress`.
- `src/music.js`: procedural soundtrack (no audio files). `scoreFor(theme, sky)` derives each biome's key, mode, chord loop, tempo, bass, arpeggio and melody; `Music.plan` is the pure arrangement and `Music.tick` schedules it from the frame loop.
- `src/postfx.js`: glow, vignette, impact punch and damage flash as one post pass. `src/settings.js`: persisted on/off preferences shared by the title settings and the engine.
- `src/boss-cards.js`: name and epithet per world for the boss introduction card.
- `src/tutorials.js`: persisted first-introduction lessons. Other modules build worlds, props, bosses, pooled effects and synthesized audio.

## Run and verification
- Railway deployment uses the root Dockerfile and Caddyfile to serve only index.html, src and vendor. Caddy listens on Railway's PORT, defaulting to 8080. No application build step is required.
- Railway project: SwarmSurge (85f13dc6-b388-49b6-8958-ac97f96b5d56), production environment e72c5f09-fe4f-4302-b2d0-a32eb632bbe8. Deploy the GitHub main branch through the connected Railway service.
- Serve from the root: `python3 -m http.server 8000 --bind 127.0.0.1`. Open `http://localhost:8000/index.html`.
- Drag horizontally, use arrow keys or A/D to aim. Firing is automatic. Pause with the HUD button, Escape or P.
- `?level=12&stage=2` starts a selected stage. `speed=2` accelerates simulation; `turbo=1` skips rendering for bots.
- Debug through `window.__game.state` and `window.__game.dbg(source)`. Inspect desktop and mobile bounds when changing UI.
- Install check dependencies with `cd tools && npm ci`. Run `CHROME_PATH=/path/to/chrome node check-game.mjs`. Add `--campaign` for all 50 worlds with the smart policy and seed 42, or `--levels=8,19` for selected worlds. Reports are ignored under `tools/out/`; selected runs preserve the full campaign report.
- Compare difficulty with `CHROME_PATH=/path/to/chrome GAME_URL=http://127.0.0.1:8000 node tools/balance-checks.mjs --levels=1,4,8,16,19 --policies=smart,naive,center --seeds=42`. Each world resets its seed and policy state. Reports include stage times, attempted cannon damage, boss attacks and sampled aim holds. This tool defaults to port 8001 for isolated tuning.
- Run tutorial policy checks with `node tools/tutorial-checks.mjs` from the root. Run mobile resolution checks with `CHROME_PATH=/path/to/chrome node tools/mobile-quality-checks.mjs`. No test script is configured in package.json.
- Run `CHROME_PATH=/path/to/chrome node tools/asset-checks.mjs` for boss geometry, deterministic poses, collision metadata, fort bounds, defense and late mechanic model contracts, and roster coverage of all 50 worlds.
- Late-world balance: `balance-checks.mjs --levels=21,...,50 --policies=smart --seeds=42,7,99,1234,5`. The campaign checker chains one RNG across worlds, so a selected world can behave differently from the same world in the full run.
- Older optional bots hardcode `/usr/bin/chromium`; older screenshot tools assume `/tmp/ss`. Adapt them before use on macOS. The main checker polls readiness on a timer because background headless tabs can throttle animation frames.

## Current behavior
- Battle feel: defeated units are flung as tumbling bodies (`makeToss`, 72 per pool, far geometry, not in turbo); troops stop, face the camera and hop while a stage is cleared; a new troop body form shows an EVOLVED popup once per stage; short hit-stops mark fort and boss kills, nukes, heart losses and big enemies; the advance between stages widens the lens. The first time a run reaches a boss, a 2.6 s introduction holds the simulation while the camera sweeps across the boss, it plays its attack pose and a letterboxed name card shows. A tap or aim key skips it; retries, turbo and reduced motion never show it. Hit-stops and the introduction live in `frame`, so headless bots and checks are unaffected.
- Split gates replace existing multipliers of the same strength (`PRISMS` and `MIRRORS` in `src/campaign.js`), so stage totals stay as tuned. A prism portal takes a x3 and sends one copy of each troop to each of three exit pads (worlds 9, 16, 20, 24, 25, 26, 30, 46, 49); a mirror gate takes a x2 and adds a twin across the road (worlds 14, 18, 27, 28, 29, 31, 40, 50). The exit nearest the prism keeps the original troop, so a full pool folds power into the lane it was already in. Place them only where every exit lane leads to gates of equal value: a prism before a narrow center ladder or a mirror on an asymmetric road measurably slowed the stage. Each has a one-time lesson (worlds 9 and 14).
- Worlds 21 to 50 introduce one mechanic per five-world arc, each with a first-introduction lesson: 21-25 bumpers (multiply each blue unit once and bounce it sideways), 26-30 hypno gates (absorb troops to charge, then convert crossing enemies for a timer), 31-35 mine carts (troops push them along rails to blast the target), 36-40 harvest banks (store troops and return a multiplied batch after a timer), 41-45 eggs (smash for blue hatchlings or they hatch enemies) and 46-50 fusion cores (paired charge fires a beam that multiplies troops and damages the target). Later arcs mix earlier mechanics.
- Late worlds restart from one barrel. Their flanks carry a fixed toughness budget (pairs for heavy kinds, weaker ghost pairs, three for light kinds). Stage one and boss stages get a single flank, stage two gets two. Equipment costs stop rising after world 20.
- Normal startup opens the animated title screen. Play opens the existing campaign map; its Home button returns to the title screen without losing a resumable battle. Debug level URLs still start directly. Settings reuse the audio preference and separately persist menu motion. The camp never advances gameplay or consumes tutorials/progress; it updates at up to 30 Hz only while visible and focused. Disabled or system-reduced motion renders a still scene, and the camp stops behind the map or a battle.
- Balls absorb contact and ranged damage during deployment and rolling, including continuous collision against fast troops. Overkill preserves unused troop power and grants four seconds of x2 cannon output. Frost and impact timers expire during deployment too. Charged giants preserve their output when the troop pool is full.
- Rapid doubles rate up to x8; Power triples output. Levels accumulate a mixed arsenal through crates, with multiplication copies retaining their weapon. Equipment persists across stages and stage retries. Escorts mirror cannon volleys and reinforce armor.
- Weapons have separate ranges, cooldowns and effects: blasters, rocket splash, chain lightning, scatter cones, piercing railguns, burning flames, frost slow and plasma splash. Spatial targeting respects cover and reserves firing capacity for troops with actual targets.
- Mixed arsenals can trigger Shatter and Ignition. Railguns consume frost for x1.6 hit damage; plasma consumes burning for x1.4 damage. Reaction feedback is limited to once per second and does not create troops. Worlds 10 and 16 supply frost plus rail; Factory and the finale supply flame plus plasma.
- Two forms sit past the Titan and only come from their own crates (`tank` crates stop at the Titan, `TANK_EVOLUTION_CAP`). The Prism lancer (arrowhead hover skiff, hoop with three orbiting crystals) fires a lance down the aimed lane every 4.5 s: it ignores armor, removes 15% of a wall's strength per beam, skips vault seals and deals at most 2.5% of the target's HP. The Dreadnought (tracked hull, ram bow, stepped citadel, rotary sponsons, mortar battery, radar) drops four shells every 6 s on the heaviest enemy packs, with spare shells on the target at 1% each. Ability damage follows the army like air strikes (`ABILITY_SPECS`). They deploy two new troop weapons: mortars lob over gates and walls (`lob`), shock lances shove enemies back up the road and slow them (`knock`, never through a wall or past the fort line). Worlds 27, 33, 36, 39, 41, 43, 46, 48 and 50 supply them; boss HP in 43 and 50 was raised to keep fights at 14 to 21 s.
- Bulldog, Siege, Spider, Hover, Rail and Titan forms have animated shells, specialist equipment and armor. Transformations never downgrade a stronger form. Grounded treads and feet stop at zero speed; breathing and hover idle motion remain. Barrels have recessed bores and coolant ports, with flashes at the actual muzzle. Hulls, turrets, fenders, limbs and wheels are lofts, lathes and sweeps (cast turrets, rocket pods, a curved dozer blade, ducted fans, domed pauldrons); node names, pivots and mount anchors are unchanged. The starting carriage is a rounded mortar housing on four spoked wheels; vehicle forms seat the charge orb on a pedestal.
- Air upgrades progress through Scout interceptor, Strike jet and Stealth bomber. Higher grades strike more frequently, deal more damage and cover a wider lane. Each pass keeps its captured grade until it finishes. Models are cached lazily; hangars use the same aircraft assets. Fuselages, wings, fins, canopies and nacelles are lofts and lathes; color zones are separate pieces with shared joins because per-vertex bands blur on coarse lofts. They cost 3.5k to 5.2k triangles (previously 0.8k to 1.3k), with one aircraft visible at a time.
- Armor absorbs each cannon hit before hearts. Full blocks use a shield response without false heart-loss feedback. Only overflow damages hearts, including when healing occurs in the same update.
- Heart pickups can raise lives to fifteen. Results show the remaining total rather than dividing bonus hearts by the ten starting lives.
- Destroyed bunkers are removed before their reinforcement timer is handled, preventing a final wave after a lethal hit.
- All 60 stages have equipment routes and revised pacing. Normal late stages have limited, announced biome flanks; surge routes retain their overpowered rhythm. Long fights expose armor up to x4 hit damage. Moon Base and the stationary Neon Nights opening were shortened after balance measurements.
- Boss HP uses a per-world multiplier (`BOSS_HP` in `src/campaign.js`) calibrated against bot damage curves. Armies grow exponentially, so fight length needs large HP factors (x1.5 to x50). The seed-42 smart bot's median boss fight rose from 10.9 s to 23.6 s; most normal fights now last 15 to 30 s, with outliers from 7 s (world 16, seed 7) to 41 s (Moon, seed 7). Worlds 9, 10 and 19 end in deliberate OP bursts that ignore boss HP; World 2 already ran 31 s and is unchanged.
- Defeated forts and bosses shatter into spatial chunks (`FX.shatter`): triangles are binned into a coarse grid, so each chunk carries every material in that region. Moving whole meshes used to peel one material layer (roofs, trim, stone) off the entire model and leave see-through gaps. Chunk geometry is private and disposed when the effect ends; materials stay borrowed.
- Difficulty targets moderate pressure, short encounters and rewarding OP routes. Breakable gates and defenses have more HP, with smaller increases in the tutorial and surge stages. Armored enemies resist weapons, burning and aircraft; railguns pierce their armor. Normal bosses endure longer and alternate announced cannon sweeps with their signature attacks. Moon retains its crusher pattern without an extra sweep, and its opening keeps a gentler enemy warmup.
- Optional sealed routes appear in world 4 stage 1, world 6 stage 2, world 12 stage 1 and world 16 stage 1. Their narrow seals guard x100, x100 and x1000 gates, with a moving first gate and short phase windows aligned to normal troop travel. The complete prize multiplies power by ten million. Reward gates explicitly require their seal to be destroyed, so side entry, jumping or teleporting cannot bypass the unlock. Normal routes remain available. Narrow collision widths and enlarged, staggered labels are separate.
- Upgrade and hangar costs rise by stage. At entry, costs also account for the main cannon's inherited barrels, rate and power, with minimum investments of 3.2 seconds in stage two and four seconds in stage three before multipliers. Mirrored cannons and escorts are excluded because they cannot all hit one crate. Prices stay fixed during a stage and retries restore the same entry price. New upgrades do not raise other prices midway through a fight.
- World 2 stage 1's divider starts at distance 14.5, meeting the fence at distance 15. Keep this junction closed so troops must break the fence before entering the multiplier ladder.
- The island map unlocks worlds progressively and preserves legacy saves. Victories save before result animation. The map can retain one exact in-memory battle until another world starts or the page reloads.
- Basic tutorials appear only on first introductions in world one. Movement gate variants share one lesson. Replays, retries, existing wins and debug starts skip repeated prose. Opening the map does not consume a lesson.
- A drag stays attached to its first pointer until release, cancellation, lost capture or pause. Mouse aiming starts only with the primary button. Focus loss clears held input and pauses simulation, audio, HUD animation and rendering. Resize redraws a frozen scene once. Progress, mute and tutorials use separate localStorage keys. Blocked or full storage does not prevent startup or mute changes; unavailable persistence falls back to session memory.
- New runs clear smoothed army counters, popups, recoil, camera kick and damage or nuke flashes. Resuming the in-memory battle retains its simulation state.

- Music: every world has its own generated score (bright skies get major or mixolydian, dark skies minor or phrygian). The arrangement follows battle heat from army power, enemy count and low hearts: pad and arpeggio first, then bass, kick, hats, snare and lead. Boss stages turn to the parallel minor, speed up by 12 BPM and add a downbeat boom. The title, map and results play a slow camp theme. Music ducks under the clear, victory and defeat jingles, uses its own gain bus behind a compressor, and stops with pause, lost focus, the Sound mute or the Music setting (`swarm-music`). The first gesture anywhere unlocks audio. Turbo runs never tick it.

- Records and medals: a win stores the world's best army, combo, kills and battle time. Three medals per world: Flawless (no hearts lost), Swift (under 65 s of battle) and Overpowered (boss beaten in under 12 s). Times and medals need a run that started at stage one; a stage retry continues the same run (clock, tallies and lost hearts carry over). The results screen shows a time tile, "NEW BEST" or the standing best per tile and the medal row; the map shows three medal pips beside the stars, a gold number for a mastered world and the medal total in the header; the pause dialog lists the goals and strikes out the ones the run can no longer reach.

- HUD polish: the target row names the boss from its card (without "The") instead of "Boss"; a pale ghost bar trails the health fill on the way down and snaps on refills or new targets; a battle clock sits under the stage pips and dims once Swift is out of reach; a pulsing red edge shows at two hearts or fewer during play (static with reduced motion, hidden in the boss introduction). The pause dialog has Sound, Music and Glow toggles that share state with the title settings and the HUD mute button.

## Visuals and resource ownership
- Allied troops change body form with rank: Surge bot (ranks 1 to 3), Trooper (4 to 6), Paladin (7 to 9) and Ascended (10 to 13). Each form has near and far instanced meshes; empty meshes are hidden. All forms share the hip pivot, hand anchors and footprint, so weapons, stride and collision are unchanged. Enemies use a horned raider with sculpted bomb, shield, tank helmet, drone jetpack and crab carapace overlays.
- Near troops cast shadows through shadow-only proxies (layer 1, rendered only by the sun's shadow camera) that reuse the far geometry and share the near instance buffers. Troop shadow triangles dropped from about 1.55M to 0.57M in an 850-troop scene with no visible difference. Distant troops also use low-detail weapons and enemy gear (`detail = 'low'`). The near/far threshold (24 px, 20 px hysteresis) was kept because the far body is visibly blockier up close.
- Troops use instanced stride animation with matching shadow shaders. Projected-size detail selection preserves colors, weapon placement and motion phase. Sleeping, flying and airborne units stop walking. Rolling balls use the lighter troop geometry.
- Drones have jetpacks and winglets, crabs have shell plates and claws, and ghosts have halos and wisps. Floating bodies and weapon aim heights agree; special lights share a twelve-point budget.
- All 32 boss types have native rigs with separate silhouettes and equipment, including the lunar explorer, candy sovereign, articulated Kraken, lantern Pumpkin King, the world 10 void colossus Titan (slit helm, spiked gauntlets, pulsing core, floating shard halo; no longer a recolored skeleton), coil-backed Thunder guardian and armored royal Emperor. Their root transforms stay under engine control; attack poses use the full 1.25-second cycle, and stationary or stunned legs stop walking. Rendering preserves authored boss scale. Boss rig geometry belongs to the level; the asset kit materials are shared. The old primitive boss builders have been removed.
- All bosses use continuous shaped anatomy, carved faces, curved shells, domed armor and folded cloth. Skin, forged metal and cloth use separate shared materials. The user rejected the previous stacked block construction; both obsolete block-model modules have been removed. Asset batches preserve authored vertex shades. The boss triangle budget is 40,000 per rig, with one boss visible at a time.
- Boss camera framing fits a conservative upper corner below the HUD, widening only when needed. Both desktop and portrait boss openings were checked for obstruction.
- Primary boss and fort health stays in the fixed target bar. Damage numbers alternate beside the target with one active number per flank, expire cleanly and hide when no side space remains. Decorative forts carry no misleading HP label. HUD size observation and a reserved target text row keep framing current as content changes.
- Forts use eight architecture families across fifty biome palettes: bastion (machicolated round towers, conical roofs), temple (stepped tiers, shrine, carved mask), crown (onion domes with icicles, clouds or candy bands), station (modules with observatory, mast or chimneys), gothic (buttressed spires, lancet windows), reef (turret-shell spire, coral), prism (hex column, crystal cluster) and casino (gold dome, chip, marquee bulbs). The curtain wall bends back toward the towers; stone courses frame windows and the gate. Banner and gate groups keep their names and animation. Turrets aim and recoil with beams starting at their muzzle. Bunker doors respond to reinforcement spawns; crusher rods follow the moving ram. Props retain their collision dimensions and add no lights or raster textures.
- Gates use lathe pylons with trim collars, glowing caps and side strips, a rounded lintel, a ramped sill and floor chevrons. Caps and frame follow `setColor`; the collar trim material is shared.
- Storm Peaks clouds stay in lateral banks. Open wind spirals leave gate labels visible through tornadoes. HUD panels exclude world health labels; the fixed target bar shows remaining HP and percentage. Future-stage geometry is hidden.
- The frame loop skips animation callbacks closer than 9 ms, so 120 Hz screens render at 60 fps (the simulation rate) instead of repeating frames; 90 and 100 Hz screens keep their rate.
- On touch devices, sustained slow frame timing can lower the rendering pixel ratio in steps and restore it after recovery. Stable 30 Hz cadence and long interruptions do not trigger a reduction; glow sizing follows resolution changes. Text shadows avoid duplicated letter silhouettes. Landscape phone layouts place the target bar below the level name and lower banners clear of it.
- Dynamic instance and point buffers upload only their used prefix through `FX.uploadUsed` (update ranges); empty meshes skip the upload. Burst particles are packed at the front each frame, sparks draw up to their highest live slot and idle debris skips its matrix rebuild. An 850-troop scene went from about 1.9 MB to 0.23 MB of instance uploads per frame.
- Every frame goes through `createPostFX` (`post.render`), not `renderer.render`. The scene renders into a 4x multisampled 8-bit target flagged `isXRRenderTarget` with `internalFormat = 'RGBA8'`, which keeps three.js tone mapping and sRGB encoding in the material shaders, so colors match the old direct render (without the explicit format the MSAA resolve fails and the canvas is black). A thresholded five-level dual-filter bloom is screen-blended on top with a vignette; `applyTheme` sets strength from biome luminance (strong on dark worlds, faint on snow and sand). The red damage flash and the chromatic punch on big shakes are composite uniforms (`G.hurtT`, `post.state.punch`); the old `#flash` DOM layer is gone. The Glow setting (`swarm-glow`) turns bloom off; on touch devices slow frames disable glow before lowering resolution and restore it last. Cost: about +0.2 ms of frame JS; GPU cost on physical phones is unmeasured.
- Transparent double-sided panels (gates, portals, fences, disks) set `forceSinglePass`. Without it three.js draws each one twice and invalidates its material every frame, which re-resolved shader programs for about 12% of the frame's JavaScript. Keep the flag on new double-sided transparent materials.
- Shader link logs are not read unless `?shaderdebug=1` is set; `warmShaders` compiles all three stages when a level opens. Static world scenery composes its matrices once, hidden stage groups skip matrix updates, and late mechanic labels redraw at 12 Hz. Frame JavaScript in a 316-troop world 20 scene dropped from 2.41 ms to 1.57 ms and draw calls from 194 to 171.
- Tracers use 128 reusable slots; splash rings use 64. Halo and combo effects are capped. Shared geometry/material templates live for the module lifetime. Level cleanup releases instance buffers without disposing borrowed templates, including grouped effects.

- Battle feel: 77 engine checks, 17 tutorial checks and asset contracts pass. Boss introductions were inspected on desktop, 390 x 844 and 844 x 390 (worlds 3, 13, 18, 50); staged kills and a staged clear confirmed the toss and the cheer. Motion quality itself was judged from stills only.
